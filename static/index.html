Make a crash. Make the case.

01

Create a baseline

Keep journaling on. Create notes.txt with “OS project”, then run to completion.

02

Recover a committed edit

Edit it to “OS project completed”. Step through BEGIN, LOG, COMMIT and DATA. Crash, then recover. The edit is restored from the journal.

03

Compare without a journal

Reset, turn journaling off, and recreate the baseline. Edit, run only DATA, then crash and recover. A size/checksum mismatch remains.
